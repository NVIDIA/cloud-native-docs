Spectro Cloud PaletteAI with the NVIDIA GPU Operator#

About the GPU Operator with PaletteAI#

PaletteAI is a Kubernetes-native platform where platform teams manage the infrastructure for AI workloads, including GPU-accelerated clusters. PaletteAI provisions Kubernetes clusters from cluster profiles, which define the operating system, Kubernetes, networking, and storage. Spectro Cloud built the validation cluster from PaletteAI cluster profiles, not by hand. A cluster profile layer installs the NVIDIA GPU Operator with the NVIDIA STIG and FIPS driver container.

For more information, refer to the PaletteAI documentation.

Prerequisites#

The validated configuration uses the NVIDIA gpu-driver-stig-fips driver container, which has its own prerequisites:

  • You must have an active NVIDIA AI Enterprise subscription and an NGC API key, provided to the cluster as a pull secret, so that the cluster can pull the driver container.

  • You must provide an Ubuntu Pro token so that the driver container can download the kernel headers for the FIPS kernel.

Refer to Prerequisites in NVIDIA GPU Operator Government Ready for the complete list.
